# make-knowledge-cards

把文章转换为 5~8 张知识卡片的 AI Agent Skill。输入用户粘贴的文本或本地 Markdown/TXT 文件，输出每张包含「标题、核心知识、简明解释、例子/自测问题」的卡片，便于学习与复习。

## 项目解决什么问题

读完一篇长文章后，常见困境是：信息密度高，抓不住重点；看的时候"都懂了"，合上文章就忘；想要复习，却没有结构化的提炼形式。

本项目的做法：让 AI Agent 自动完成"读懂 → 提炼 → 去重 → 成卡"的工序，把任意文章压缩成一组可直接复习的知识卡片。每张卡片只讲一个知识点，并自带一句话概括、通俗解释和自测问题，读完卡片即可检验自己是否真正理解。

它不追求"多"，而追求"准"：只保留原文真正重要的知识，不编造原文没有的内容，信息不足时不强行凑满 5 张。

## 主要功能

- **输入灵活**：支持对话中直接粘贴文本，也支持读取本地 `.md` / `.txt` 文件。
- **自动提炼**：通读全文，只提取真正重要的知识点（概念、原理、方法、关键数据、结论），省略铺垫、客套、轶事与重复论述。
- **一张卡片一个知识点**：不把多个知识点塞进一张卡，也不把一个知识点拆散到多张卡。
- **内置去重**：同一知识点在原文多处出现时自动合并。
- **不编造**：所有卡片内容均源自原文，不添加原文没有的事实、数据或观点；观点性文章如实转述其立场。
- **不强行凑数**：知识点不足 5 个时按实际数量输出并说明；内容空洞时如实告知，不强行生成。
- **即取即用**：输出为标准 Markdown 卡片，可直接复制到任何笔记软件。

## 安装方法

本项目是一个纯指令型 Skill：**无脚本、无依赖、不调用任何外部服务**，安装就是把目录放到合适的位置。

1. **准备一个支持 Skill 机制的 AI Agent**，例如豆包办公模式、OpenAI Agents SDK / ChatGPT 等。
2. **复制 Skill 目录**：把 `skills/make-knowledge-cards/` 整个目录（含 `SKILL.md` 和 `agents/`）复制到你所用 Agent 的技能加载目录。常见位置因平台而异，例如：
   - 豆包办公模式的用户技能目录（`workspace/.user_skills/`）
   - OpenAI Agents 项目的 `skills/` 目录或其他已配置的技能加载路径
3. **无需其他安装步骤**：不需要 `pip install`、不需要配置环境变量、不需要网络连接，Agent 会在收到相关请求时自动加载 `SKILL.md`。
4. **验证安装**：对 Agent 说"把下面这段话做成知识卡片"并粘贴一小段文本，若能输出符合模板的卡片即安装成功。

## 使用方法

安装后，直接对 Agent 提出转换请求即可，例如：

- "把这篇文章做成知识卡片"（随后粘贴文本）
- "帮我读取 `notes.md`，提炼成复习卡片"
- "把 `读书笔记.txt` 转成 5~8 张学习卡片"

Agent 会自动按 `SKILL.md` 中的流程执行：完整读取 → 提炼知识点 → 筛选去重 → 规划卡片（5~8 张）→ 撰写 → 质量核查，最终输出 Markdown 卡片。每张卡片固定包含四个字段：

| 字段 | 内容 |
|---|---|
| 标题 | 知识点的简短名称 |
| 核心知识 | 一句话概括这个知识点 |
| 简明解释 | 2~5 句通俗讲解，不看原文也能理解 |
| 例子 / 自测问题 | 一个具体例子，或一个能检验理解的自测问题 |

## 输入与输出示例

**输入**（用户粘贴的短文）：

> 光合作用是绿色植物利用光能，把二氧化碳和水转化为储存能量的有机物（主要是淀粉）的过程。这个转化发生在叶绿体中，分为光反应和暗反应两个阶段。光反应需要光照，在类囊体薄膜上进行，把水分解产生氧气，同时把光能转化为化学能储存在 ATP 中。暗反应在叶绿体基质中进行，利用 ATP 提供的能量，把二氧化碳固定并还原为有机物。光反应是暗反应的能量来源，暗反应是光反应的物质归宿，两者相互依存。

**输出**（完整版见 `SKILL.md`，此处截取前两张）：

```markdown
## 卡片 1｜光合作用的定义

**核心知识**：光合作用是绿色植物利用光能，将二氧化碳和水转化为储存能量的有机物（主要是淀粉）的过程。

**简明解释**：光合作用相当于植物的"能量工厂"：用太阳光当能源，把空气中的二氧化碳和水合成为含能量的有机物（主要是淀粉），把光能"存进"化学键里。

**例子 / 自测问题**：植物在阳光下越长越重，增重的物质主要来自哪里？（提示：来自空气中的二氧化碳和水，而非土壤。）

## 卡片 2｜光合作用的场所与原料

**核心知识**：光合作用发生在叶绿体中，原料是二氧化碳和水，产物是有机物和氧气。

**简明解释**：叶绿体是光合作用的车间；二氧化碳从气孔进入，水由根部吸收，两者在叶绿体里转化，氧气作为副产品释放。

**例子 / 自测问题**：判断正误：光合作用不需要水，只需要二氧化碳。为什么？
```

**更多真实示例**：`examples/` 目录内置四篇不同文体的测试文章（方法论、技术概念、科普短文、无信息流水账），可自行用它们体验完整输出。

## 目录结构

```
skill/
├── README.md                                    # 本文件
├── examples/                                    # 测试用示例文章（不同文体）
│   ├── article-pomodoro.md
│   ├── article-callback.md
│   ├── article-maple.md
│   └── article-trivial.txt
└── skills/
    └── make-knowledge-cards/                    # Skill 本体
        ├── SKILL.md                             # 功能说明与执行指令（核心）
        └── agents/
            └── openai.yaml                      # OpenAI 兼容元数据（name/description/license）
```

## 暂不支持

- 网页抓取（粘贴链接不代为抓取）
- PDF、图片、Word 等其他格式（仅支持纯文本与 `.md` / `.txt`）
- Anki 导入导出
- 图形界面 / 卡片美化排版
