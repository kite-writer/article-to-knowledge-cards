# Make Knowledge Cards

把文章转换为知识卡片：先完整读懂原文，再提炼真正重要的知识点，按"一张卡片一个知识点"的原则组织成 5~8 张卡片，方便学习与复习。

## 输入来源

从以下任一来源获取文章全文：

- 用户直接在对话中粘贴的文章文本。
- 用户提供的本地 `.md` / `.txt` 文件（先完整读取文件内容，不跳过任何段落）。
- 当前对话上下文中已附带的文章（如用户上传的纯文本附件）。

**不支持**的输入：网页链接（不代为抓取网页）、PDF、图片、Word 等其他格式。遇到这类输入，先明确告知本 Skill 不支持，再建议用户改为粘贴文本或提供 .md/.txt 文件。

## 处理流程

1. **完整读取**：通读全文，理解文章主旨与结构，不因篇幅长而跳读。
2. **提炼知识点**：识别全文的核心知识点——概念定义、机制原理、方法步骤、关键数据、因果结论、重要观点。区分核心知识与铺垫、客套、轶事、次要细节。
3. **筛选去重**：合并表达同一知识点的多处论述，删除重复内容与无关信息。
4. **规划卡片**：按知识点拆分卡片，每张卡片只讲一个知识点，控制在 5~8 张。知识点不足 5 个时按实际数量输出，不强行凑数；知识点超过 8 个时，合并相近的知识点或只保留最重要的 8 个，并在开头说明取舍。
5. **撰写卡片**：按下方卡片模板逐张填写。
6. **质量核查**：逐条对照原文，确认每个知识点都有原文依据，没有编造、没有遗漏原文明确表达的重要观点。

## 卡片模板

每张卡片使用以下结构，按知识点在原文中的重要性排序输出：

```markdown
## 卡片 1｜<标题>

**核心知识**：<一句话概括这个知识点>

**简明解释**：<2~5 句，用通俗、自洽的语言讲清楚，让读者不看原文也能理解>

**例子 / 自测问题**：<给出一个具体例子，或一个能检验是否真正理解的自测问题，二者可同时给出>
```

标题取知识点的简短名称；简明解释聚焦知识点本身，不重复其他卡片内容；例子优先用原文已有的事例，自测问题优先用原文事实作答。

输出开头可加一行简短说明（例如"根据《文章标题》共整理 6 张卡片"或"该文章可提炼的知识点较少，共 N 张"），随后按卡片顺序输出。

## 质量守则

以下规则为硬性要求，任何情况下不得违反：

- **一张卡片只讲一个知识点**：不把多个知识点合并进同一张卡片，也不把同一知识点拆散到多张卡片。
- **只提取真正重要的知识**：优先保留概念、原理、方法、关键数据与结论；省略寒暄、铺垫、轶事和重复论述。
- **删除重复内容**：同一知识点在原文多处出现时合并为一张卡片。
- **严禁编造**：卡片内容必须全部源自原文。不添加原文没有的事实、数据、例子或观点；原文措辞模糊处沿用原文表述，不作过度引申。
- **不强行凑数量**：全文可提炼的知识点不足 5 个时，按实际数量输出，并在开头注明"该文章可提炼的知识点较少，共 N 张"；文章内容空洞、无实质信息时，先指出这一问题，不强行生成卡片。
- **如实呈现原文立场**：原文为观点性或争议性内容时，卡片如实转述，不自行增删立场。

## 输出示例

输入（用户粘贴的短文）：

> 光合作用是绿色植物利用光能，把二氧化碳和水转化为储存能量的有机物（主要是淀粉）的过程。这个转化发生在叶绿体中，分为光反应和暗反应两个阶段。光反应需要光照，在类囊体薄膜上进行，把水分解产生氧气，同时把光能转化为化学能储存在 ATP 中。暗反应在叶绿体基质中进行，利用 ATP 提供的能量，把二氧化碳固定并还原为有机物。光反应是暗反应的能量来源，暗反应是光反应的物质归宿，两者相互依存。

输出：

```markdown
## 卡片 1｜光合作用的定义

**核心知识**：光合作用是绿色植物利用光能，将二氧化碳和水转化为储存能量的有机物（主要是淀粉）的过程。

**简明解释**：光合作用相当于植物的"能量工厂"：用太阳光当能源，把空气中的二氧化碳和水合成为含能量的有机物（主要是淀粉），把光能"存进"化学键里。

**例子 / 自测问题**：植物在阳光下越长越重，增重的物质主要来自哪里？（提示：来自空气中的二氧化碳和水，而非土壤。）

## 卡片 2｜光合作用的场所与原料

**核心知识**：光合作用发生在叶绿体中，原料是二氧化碳和水，产物是有机物和氧气。

**简明解释**：叶绿体是光合作用的车间；二氧化碳从气孔进入，水由根部吸收，两者在叶绿体里转化，氧气作为副产品释放。

**例子 / 自测问题**：判断正误：光合作用不需要水，只需要二氧化碳。为什么？

## 卡片 3｜光反应与暗反应

**核心知识**：光合作用分光反应和暗反应两个阶段；光反应在类囊体薄膜上进行并释放氧气，暗反应在叶绿体基质中进行并固定二氧化碳。

**简明解释**：光反应"接电"（需要光照，把水分解出氧气，并把光能转化为 ATP 中的化学能），暗反应"用电"（利用 ATP 能量把二氧化碳固定还原成有机物）。两者一个产能量、一个用能量。

**例子 / 自测问题**：为什么黑暗环境下植物不能持续进行光合作用？（提示：光反应需要光才能为暗反应提供 ATP。）

## 卡片 4｜光反应与暗反应的关系

**核心知识**：光反应为暗反应提供能量（ATP），暗反应是光反应的物质归宿，两者相互依存。

**简明解释**：没有光反应，暗反应就没有能量可用；没有暗反应，光反应积累的 ATP 无处消耗，反应链条会中断。二者缺一不可。

**例子 / 自测问题**：用一句话说明：切断光照后，暗反应能否立即停止？为什么？
```

## 边界说明

- 输出为 Markdown 文本，可直接复制到笔记软件；不做图形化排版、不生成图片卡片。
- 不提供 Anki 导入导出、不调用网页抓取、不处理 PDF。
- 用户提出超出上述范围的需求时，说明原因并给出替代建议（如自行粘贴文本）。
